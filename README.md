# Дискуссии у Зелёного кота

Две интерактивные песочницы по вопросам из сообщества «Космос зелёного кота».
Формулы на виду, каждая сверяется с независимым численным расчётом, код открыт.

| Песочница | О чём | Вход |
|-----------|--------|------|
| **Кориолис** | Два Starship на тросе, искусственная тяжесть, яблоко, кольцо | [`site/coriolis/`](site/coriolis/) |
| **Один виток** | Круговая НОО, наклонение, подспутниковая точка: вернёмся ли в старт за один виток? | [`site/vitok/`](site/vitok/) |

Общий индекс сайта: [`site/index.html`](site/index.html).

## Запуск

```sh
python3.12 -m http.server -d site 8000   # http://localhost:8000
npm test                                 # проверки обеих песочниц
npm run checks                           # то же, таблицей с числами
```

Сборки нет: чистый HTML + ES-модули. Формулы рендерит KaTeX с CDN.

## Правила разработки

1. **Язык сайта — русский.** Видимый текст на страницах — по-русски. Комментарии в `js/physics/` —
   на русском; README и коммиты — как удобно.
2. **Физика отдельно от интерфейса.** `js/physics/` не трогает DOM.
3. **Каждая формула — с проверкой** в `checks.js` против *независимого* расчёта.
4. **Оценки помечаются как оценки.** Упрощения модели подписаны на страницах «Физика».
5. Коммиты — conventional commits. Перед коммитом — `npm test`.

### Кориолис

Модели в инерциальной СО; центробежная сила и Кориолис не закладываются руками.
Параметры Starship — оценки. Материалы — паспортные данные с η.

### Один виток

Фокус ТЗ: **круговая НОО**, в первую очередь наклонение; разгон с поверхности и вращение Земли.
Вывод: за один виток в точку старта на НОО не вернуться (\(\Delta\lambda \approx -\omega_E T\)).
Режим «Возможности»: спектр \(T=T_{\mathrm{sid}}/N\) — от GEO (\(N=1\)) до суток на НОО (\(N\sim15\)).
Модель: сферическая Земля, без J2; разгон — упрощённый профиль, не баллистика конкретной ракеты.

## Состояние

- **Кориолис:** трос с массой/упругостью, динамика, яблоко, переход, кольцо, 16 проверок.
- **Один виток:** карта + глобус, старт/i/h/разгон, объяснение «почему нельзя», проверки в `test/vitok/`.
