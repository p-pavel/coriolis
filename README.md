# Кориолис — песочница искусственной тяжести

Статический сайт с живыми моделями: два корабля класса Starship на тросе, падающее яблоко
во вращающемся отсеке, переход по тросу, кольцевая станция на орбите. Цель — «физически честная»
песочница: формулы на виду, каждая сверяется с независимым численным расчётом, код открыт.

Обсуждение выросло из вопросов сообщества «Космос зелёного кота»: насколько реальна искусственная
тяжесть на системах класса Starship и что будет с тросом.

## Запуск

```sh
python3.12 -m http.server -d site 8000   # открыть http://localhost:8000
node --test                              # все проверки физики
node test/report.js                      # то же, таблицей с числами
```

Сборки нет: чистый HTML + ES-модули. Формулы рендерит KaTeX с CDN.

## Устройство

```
site/
  *.html                 страницы (текст только на русском)
  css/style.css
  js/physics/            физика: без DOM, работает и в браузере, и в node
    constants.js         константы, оценочные параметры Starship
    materials.js         материалы тросов и конструкций (паспортные данные)
    sizing.js            аналитика: трос с массой, кольцо, моды качания, прецессия, комфорт
    sim.js               динамика двух кораблей на упругом тросе (инерциальная СО, Верле)
    drop.js              полёт предмета во вращающемся отсеке + точные решения
    climb.js             силы при движении вдоль троса
    checks.js            проверки: формула против независимого численного расчёта
  js/ui/                 общие контролы, рисование, самописец
  js/pages/              скрипт каждой страницы
test/                    node --test обёртка над checks.js и отчёт
.github/workflows/       проверки + публикация на GitHub Pages
```

## Правила разработки

1. **Язык сайта — русский.** Весь видимый текст на страницах — на русском. Комментарии в `js/physics/` —
   на русском (их читают проверяющие физику), README и сообщения коммитов — как удобно.
2. **Физика отдельно от интерфейса.** `js/physics/` не трогает DOM. Всё, что показывает сайт,
   считается там и импортируется страницами.
3. **Каждая формула — с проверкой.** Новая формула на сайте появляется вместе с проверкой в `checks.js`,
   которая сравнивает её с *независимым* расчётом (симуляция, точное решение, численное дифференцирование),
   а не с самой собой. Допуск выбирается так, чтобы потерянный множитель или неверный знак его заведомо превышали.
4. **Модели считают в инерциальной системе.** Центробежная сила и Кориолис не закладываются руками,
   а получаются; во вращающуюся систему переводится только картинка.
5. **Числа в тексте страниц — из расчёта.** Если в HTML написано число («около 20 см»), оно должно
   совпадать с тем, что даёт код при параметрах по умолчанию; при изменении параметров по умолчанию — перепроверить.
6. **Оценки помечаются как оценки.** Параметры Starship не опубликованы точно — они в настройках и подписаны.
   Материалы — паспортные данные производителей с поправкой на реализацию прочности в канате (η).
7. **Источники — первичные.** Статьи (DOI), паспорта материалов, страницы NASA — на странице «Физика».
8. Коммиты — conventional commits (`feat:`, `fix:`, `docs:`...). Перед коммитом — `node --test`.

## Состояние и планы

Сделано: расчёт троса с массой и упругостью (сечение из прочности с запасом), плоская динамика с качанием
кораблей, волнами, провисом, рывком и обрывом, лебёдка с регулятором натяжения, яблоко (плоская палуба и кольцо),
переход по тросу, оценка кольца, прецессия оси на орбите, 16 проверок.

Дальше: трёхмерная динамика (выход из плоскости, нутация, «скакалка»), орбита и гравитационный градиент
в симуляции, плескание топлива как диссипация, перемещение людей и грузов внутри модели.
